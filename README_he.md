# פרויקט אוטומציה עם Selenium ו-Python 🧪🕸️  

זהו פרויקט בדיקות אוטומטיות עבור אתר מסחר מקוון.  
הפרויקט פותח במסגרת קורס אוטומציה וכולל:  
- בדיקות התחברות, עמוד הבית, חיפוש, אזור אישי ועגלת קניות  
- שימוש במבנה Page Object Model  
- דוחות Allure וצילום מסך אוטומטי בעת כישלון טסט  

## טכנולוגיות  
- Python, Selenium, Pytest, Allure  

## הרצת טסטים  
```bash
pytest
```
